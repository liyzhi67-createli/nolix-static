Noliz 1.1.0 更新了桌面界面：顶部导航、分类侧栏与卡片网站库，沿用原有的暖米白、苔绿配色，支持浅色和深色模式。

- 在卡片上收藏网站，在网站库中搜索收藏。
- 保留最近访问，支持清空和撤销。
- 收藏与最近访问保存在当前设备，不与网页端同步。
- 目录数据、账号和投稿继续连接现有后台；访问网站时使用默认浏览器。

Windows：下载 EXE 后直接打开，适用于 Windows 10 / 11 的 64 位电脑。

macOS：下载通用 DMG，拖入“应用程序”，适用于 macOS 13 及以上的 Apple 芯片和 Intel Mac。此版本使用 ad-hoc 本地签名，没有 Apple Developer ID 签名与公证。首次打开若被拦截，请参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

两个平台都无需另装 Node.js、Python 或浏览器。当前版本不自动更新，请通过官网下载安装新版。
