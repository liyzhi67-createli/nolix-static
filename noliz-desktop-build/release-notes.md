Noliz 1.2.0 增加独立的推荐、个人收藏、个人设置和网站详情页面，保留 Steam 风格导航与 Noliz 暖米白、苔绿配色。

- 所有账号均可设置头像、显示名称和简介，收藏、点赞并评论网站。
- 已核实到账的 ¥99 永久推荐优先，其余按点赞数排序。
- 个人收藏随账号保存，网页端与桌面端均可查看；旧版本机收藏可主动导入。
- 网站照片封面仅由指定管理员上传或更换。
- 每个账号在同一网站最多评论 2 条；收藏仅自己可见。
- 最近访问保存在当前设备，按登录账号区分。

升级前请退出旧版软件。Windows 10 / 11 64 位：下载 EXE 后直接打开。macOS 13 及以上：下载通用 DMG，拖入应用程序。支持 Intel 和 Apple 芯片。

macOS 包使用 ad-hoc 本地签名，尚无 Apple Developer ID 签名和公证，首次打开可能需要在隐私与安全性中确认。参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

两个平台均无需另装 Node.js、Python 或浏览器。本版本没有自动更新功能。
